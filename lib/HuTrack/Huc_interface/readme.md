# HuC and HuCC interface

Include `HuTrack/Huc_interface/HuTrack.c` in C. Use the matching HuC or HuCC
4.x library layout shown in [the integration guide](../../../docs/huc/huc_hutrack_doc.html).
The complete buildable examples are in `example/huc` and `example/hucc`.

See the [complete API reference](../../../docs/huc/huc_hutrack_doc.html#api-reference)
for arguments, return values, fades, SFX ownership, all PCM request forms, HuSFX
and assembly calling conventions.
