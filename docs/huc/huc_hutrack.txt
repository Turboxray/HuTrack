HuTrack: HuC 4.x and HuCC integration
Updated 10 October 2026

The complete, maintained guide is huc_hutrack_doc.html in this directory.
Open it in a web browser; the guide and its pictures work offline from a checkout.

The guide targets newer 4.x toolchains and provides separate, tested setups:

  HuC:  include/huc; lib_exclude.asm, libslot1.asm, sound.inc.
  HuCC: include/hucc; hucc-config.inc, hucc-sound.inc,
        hucc-final-extra.asm.

It includes DMF conversion commands, complete build files, ROM and RAM
placement, the music API, PCM effects, HuSFX streams, bank-crossing notes
and troubleshooting. Follow the configuration for your selected compiler;
the two compilers organize library code and data differently.

See ../compatibility.md for the official Furnace 0.6.8.3 reference,
implemented effects and deliberate playback differences. Notes, vibrato
and E5 fine tuning retain HuTrack's fast approximations. Runtime noise
volume compensation has been removed.

The old PDF is a historical document; use the HTML for current setup.
